## Codex Translation Editor 0.34.0

Published September 17, 2026.

### New Features

- **Character audio export options**: audio export now combines camera-angle variants of a character label, such as `Alex (ON)` and `Alex (Off)`, into one consolidated track by default, keeping each recording at its original timeline position. Open **Character options…** to add or remove which trailing markers get ignored, or turn on **Separate by Camera Angles per Character** to export full labels as separate tracks. See [Exporting Your Project](/docs/translation/exporting-project#audio-export).

### Improvements

- The edit history panel now attaches to its cell editor instead of the viewport, so it moves with the cell, stays within the editor's width, and scrolls internally for long histories.
- Character audio consolidation now supports overlapping recordings, after an upgrade to the bundled FFmpeg build.

Full changelog: [codex-editor 0.34.0](https://github.com/genesis-ai-dev/codex-editor/releases/tag/0.34.0).

## Codex Translation Editor 0.33.0

Published September 9, 2026.

### Improvements

- **Round-trip export now works under any media strategy**, including **Stream Only**. Codex downloads a needed original only when no usable local copy exists. See [Media and Storage](/docs/project-management/media-and-storage) and [Exporting Your Project](/docs/translation/exporting-project).
- Export file names no longer include a timestamp, and use the actual target language code instead of a hardcoded English one.

### Fixes

- **Subtitle import data loss**: fixed a bug where importing a subtitle file as a target could let a later overlapping cue silently overwrite an earlier cell's text and timestamps.
- **Round-trip DOCX mapping**: fixed cases where exported documents could keep the source-language text despite an existing translation, or duplicate text in headings and text boxes.
- **Hidden cells**: navigation counts, milestone cell ranges, and file/chapter translation progress now update correctly after hiding or un-hiding cells in source editing mode. See [Hide Cells That Do Not Need Translation](/docs/translation/merging-editing-source-cells#hide-cells-that-do-not-need-translation).
- The Sync button now disables immediately after being clicked, preventing duplicate sync requests while a sync is starting.
- Sync no longer treats a diagnostic path Frontier omitted from its conflict list as a fabricated conflict, which could pull in and commit unrelated remote files.
- Multi-segment cells imported from IDML now request a single structured translation instead of a follow-up repair request, reducing AI translation delays for those cells.

Full changelog: [codex-editor 0.33.0](https://github.com/genesis-ai-dev/codex-editor/releases/tag/0.33.0).

## Recent Features To Know

- A built-in audio editor can trim, splice, and re-save cell recordings without external tools.
- Milestones and subdivisions can be renamed, and milestone placement can be edited when the setting is turned on.
- Project admins can hide cells that do not need translation; hidden cells skip AI translation and exports.
- Media-heavy projects can choose **Auto Download Media**, **Stream & Save**, or **Stream Only**; round-trip export works under any of them.
- The video player can switch between audio language tracks when the video provides them.
- Speech recognition supports language auto-detection and re-transcribing existing recordings.
- Audio export can consolidate a character's camera-angle variants into one track, with options to customize or turn that off.
- Project swap and remote updates can require contributors to apply project-card updates before continuing.
- Offline and server-unreachable states allow local projects to open even when cloud services are unavailable.
- CodexConductor extension pins keep team projects on compatible extension versions through project-specific profiles.
